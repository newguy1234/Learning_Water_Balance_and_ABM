# Imbanuma cyclic irrigation: agent-based model

An interactive agent-based model of the Imbanuma (Hakusan-Jimbee) cyclic irrigation
district in Chiba, Japan. It has 4,002 paddies, 81 farmer agents with different
personalities, and a pumping station that reuses drainage. Set the levers under
**Simulation settings**, then press **Run** or **Step** and watch the water move on the maps.

Note: all visitors currently share one simulation, so if someone else presses Reset,
your run resets too.

Source code and instructions for running it locally are in the project repository.
